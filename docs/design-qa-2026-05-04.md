# Design System QA Sweep — 2026-05-04

Pre-illustration audit of the BesideHer v2 branch, run before commissioning custom Canva illustrations.

Each finding is a checkbox. Items are organized by screen, with **Light mode** / **Dark mode** sub-sections. System-wide issues come first; commission priorities and design-system fixes are summarized at the end.

---

## 0. System-wide issues (affect every screen)

### Light mode
- [ ] `Color+Theme.swift:54-57` — **Color.paper (#F6F1E8) and Color.surface (#FBF8F2) differ by only ~3%.** Cards relying solely on `.premiumShadow()` (no hairline) read as floating cream-on-cream. Most cards do add a hairline overlay, but several heroes do not (see HomeView / AllWeeks / WeekDetail / LaborBag / EditorialCard items below).
- [ ] `Color+Theme.swift:69` vs paper — **`inkSecondary` on `paper` is ~4.6:1.** Right at the WCAG AA body threshold; will fail for any 13pt caption that lands on subtle backgrounds. Used pervasively for captions.
- [ ] `Color+Theme.swift:77` vs paper — **`accent` (terracotta #B5572E) on `paper` is ~4.3:1, fails AA for normal text.** Anywhere `Color.accent` is used as readable text on cream (Settings row values, "T1/T2/T3" pills, "Your pregnancy companion for dads" tagline, etc.) is technically below contrast.

### Dark mode
- [ ] `Shadow.swift:14` — **`.premiumShadow()` is `Color.black.opacity(0.04)`.** A black shadow on `#14110E` paper is invisible in dark mode. Every card that depends on the shadow alone (no hairline overlay) loses its edge entirely. Recommend: in dark mode, drop the shadow and rely on hairline + `surface`/`paperTinted` luminance step.
- [ ] `Color.surfaceElevated` is **defined but never used in any view** (grep finds zero references outside the design system file). Dark mode has a 3-level surface ladder that's unused — your hero cards could use `surfaceElevated` (#272320) instead of `paperTinted` to feel raised.

### Cross-cutting
- [x] No literal hex / `Color.white` / `Color.black` / `Color(.systemX)` in views. (only `Color.black` is inside `Shadow.swift`'s drop-shadow color, flagged above)
- [x] No gradients anywhere.
- [x] No emoji in any Swift file.

## 1. HomeView (`HomeView.swift`)

- [ ] `paperTinted` and `surfaceElevated` resolve to **identical color in dark** (`#272320`). Hero card and a tasks-card layered above it would look like one block — consider using `surfaceElevated` for hero and `surface` for tasks to recover the luminance ladder.

### Other
- [ ] **Contraction Timer CTA** (`HomeView.swift:207-235`): no eyebrow above. Every other section on this screen has an eyebrow ("WEEK X OF 40", "PROGRESS", "THIS WEEK", "DAD QUESTION") — this row is the odd one out.

## 4. TipsCategoryView + TipsListView

### Light mode
- [ ] **`Color.alert` used as Labor Prep category tint** (`TipsCategoryView.swift:19`). `alert` is your error / contraction-active color — using it as a category brand tint mixes semantic meaning. Pick a different token (e.g., `accent` already used for Emotional Support, so introduce a 4th tint or use `clay` here and remap Home & Gear).
- [ ] **`Color.inkSecondary` used as Postpartum category tint** (line 20) — inkSecondary is a text color, not a brand tint; the card will look washed.
- [ ] **TipsListView is noisy** (lines 120-170): each tip card has title + bookmark button + body + 1–3 trimester pill badges. With the trimester filter chips already at the top of the screen, the per-card pills are redundant. Drop them, or move filtering exclusively into the card pills.
- [ ] **No masthead / eyebrow** on TipsCategoryView — goes straight from nav bar to category cards. Every other tab has a "WEEK / GUIDE / PROGRESS" eyebrow; Tips should have one too.
- [ ] **Two accent uses on this screen:** bookmark icon (when filled) + every T1/T2/T3 pill (foreground + accentSoft bg). With multiple pills per card and many cards, accent is everywhere.
- [ ] **T1/T2/T3 pills use `Color.accent` text on `Color.accentSoft` bg** — `B5572E` on the blended tint computes to roughly 3:1, fails AA for 12pt eyebrow text.
- [ ] Tip card has `RoundedRectangle ... .strokeBorder` instead of `.stroke` (line 168) — minor, but `strokeBorder` insets by half the line width, which subtly changes the corner radius vs. other cards using `.stroke`.

### Dark mode
- [ ] `Color.alert` (#D86A4A) on a dark category card will read very loud — same semantic-mix issue, amplified.
- [ ] `inkSecondary` tint over `surface` in dark is a near-flat warm gray — the Postpartum card will look unstyled.
- [ ] T1/T2/T3 pill contrast in dark: accent (#E8B57E warm amber) on accentSoft computes to maybe 2.5:1 — fails AA badly.

### Other — SF Symbols to commission
- [ ] `heart.fill` (Emotional Support), `dollarsign.circle.fill` (Financial Prep), `house.fill` (Home & Gear), `cross.case.fill` (Labor Prep), `figure.and.child.holdinghands` (Postpartum) — **these 5 EditorialCard illustrations are the highest-value Canva commissions.** The category cards are the visual entry point to the whole content library.
- [ ] `book.closed` empty-state symbol (line 113) — could be a quiet shelf or open book illustration.

## TL;DR — top design-system fixes (no illustrations needed)

1. **Add hairline border to all unstroked hero cards** (HomeView hero + progress, AllWeeks current-week hero, WeekDetail hero, LaborBag progress, EditorialCard). Critical for dark mode.
2. **Dark-mode shadow strategy** — `Color.black.opacity(0.04)` is invisible. Either ditch the shadow in dark and rely on hairline, or build a `.premiumShadow()` that adapts.
3. **Replace `Color.accent.opacity(0.18)` everywhere with `Color.accentSoft`** (HomeView:108, AllWeeksView:100).
4. **Fix Tips category tints** — don't use `alert` (semantic) or `inkSecondary` (text token) as brand tints (`TipsCategoryView.swift:19-20`).
5. **Reduce SettingsView accent usage** — every row value in accent is too much; demote to `inkSecondary` semibold and reserve accent for the bookmark count badge.
6. **Drop per-card T1/T2/T3 pills in TipsListView** when the trimester filter chips are already on screen — redundant.
7. **Cut WeekDetailView accent count** — currently 4 distinct uses; pick one (Dad Question card is the strongest moment).
8. **Add a token for the 38pt small-timer numeral and 19pt article body** so the type scale fully covers reality.
9. **Use `surfaceElevated` somewhere** — currently defined and unused; would let dark-mode hero cards step up from `surface`.
